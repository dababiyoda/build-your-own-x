# UNIIMENTE Use of This Repository

This fork is used by the UNIIMENTE project as a **mechanism anatomy atlas**, not as a product-cloning roadmap.

Canonical founder doctrine lives in:

- `dababiyoda/uniimente-kernel/AGENTS.md`
- `dababiyoda/uniimente-kernel/docs/FOUNDER_EFFECT_COMPILER.md`
- `dababiyoda/uniimente-kernel/docs/intent/INTENT-0030-effect-not-metaphor.md`

## Mandatory rule

> **Preserve the intended effect. Do not literalize the metaphor. Extract mechanisms; do not rebuild tutorial products merely because they exist.**

When mining this repository for UNIIMENTE:

1. start from the named target effect or CapabilityDeficit;
2. inspect relevant tutorial/system categories for causal primitives;
3. extract operations, state, transitions, information flow, authority, trust boundary, resource use, feedback, proof, failure, and recovery;
4. discard source branding and product assumptions;
5. check whether the mature real implementation/library/tool can simply be used or adapted;
6. mutate/recombine mechanisms only when doing so creates a needed capability;
7. build new UNIIMENTE-owned infrastructure only when the residual deficit or strategic control requirement justifies it;
8. verify the resulting effect against the simplest viable baseline.

Do not rebuild Git, Docker, a database, an OS, a search engine, a blockchain, a network stack, or any other tutorial artifact merely to make UNIIMENTE seem more organism-like, sovereign, or science-fictional.

Examples of legitimate extraction:

- Git -> content-addressed lineage / causal versioning;
- container isolation -> bounded capability execution;
- compiler design -> founder doctrine/contracts into executable policy or workflow;
- event systems -> durable signaling and replay;
- networking -> authenticated routing / discovery mechanisms;
- databases -> specific indexing, transaction, or persistence primitives.

The source technology is replaceable. The target effect and verified mechanism are what matter.

This instruction does not modify or reinterpret the upstream educational project for other users; it governs only this fork's role inside Alfonso's UNIIMENTE project.
